Совмещение УСН и патента

ИП может совмещать режимы

Индивидуальный предприниматель вправе одновременно применять УСН по одним видам деятельности и патентную систему (ПСН) по другим — например, розничная торговля на патенте и оптовые продажи на УСН. Организации совмещать эти режимы не могут — ПСН доступна только ИП.

Раздельный учёт обязателен

При совмещении режимов нужно вести раздельный учёт доходов, расходов и, при наличии сотрудников, страховых взносов по каждому режиму — расходы, которые нельзя однозначно отнести к одному виду деятельности, распределяются пропорционально доле доходов от каждого режима.

Лимиты считаются по совокупности

Для сохранения права на УСН при совмещении с патентом лимит по доходу учитывается суммарно по обоим режимам, а не отдельно. Лимит по численности сотрудников для целей УСН также считается совместно, хотя для самого патента дополнительно действует отдельное ограничение — не более 15 работников по видам деятельности на патенте.

Рассчитать сумму налога по своим цифрам можно в калькуляторе.

Открыть калькулятор УСН

Материал носит справочный характер. Условия применения УСН установлены главой 26.2 НК РФ, точные лимиты и ставки для своего региона уточняйте на сайте ФНС.
